# Автотесты Кинопоиск: UI и API

Учебный проект автоматизации тестирования: API-тесты поиска фильмов и персон
(Кинопоиск API) и UI-тесты сайта и видеоплеера (главная страница, поиск,
«Буду смотреть», пауза, перемотка и выбор серий в плеере).

## Стек

- **Python 3.11+**
- **Playwright** — управление браузером в UI-тестах
- **Requests** — HTTP-запросы в API-тестах
- **Pytest** — запуск тестов, фикстуры
- **Allure** — отчёты о прохождении тестов
- **python-dotenv** — загрузка конфигурации из `.env`

## Структура проекта

API-tests/ # API-тесты (7 тестов: поиск, пагинация, фильтры, ошибки) UI-tests/ # UI-тесты (6 тестов: поиск, избранное, плеер) UI-tests/pages.py # Page Object для страниц Кинопоиска и плеера config.py # настройки: URL, таймауты, селекторы, тестовые данные conftest.py # фикстуры: api_get (API) и page (браузер для UI) .env # секреты (API-токен) — в репозиторий не попадает state.json # куки сессии для UI-тестов — генерируется save_state.py pytest.ini # регистрация меток ui / api requirements.txt # зависимости


## Установка

### 1. Установить зависимости

pip install -r requirements.txt

### 2. Установить браузеры Playwright (для UI-тестов)

playwright install chromium

### 3. Настроить окружение

Создать файл .env в корне проекта и положить в него API-ключ:
KINOPOISK_API_KEY=ваш_ключ

Ключ выдаётся на https://poiskkino.dev/ после регистрации.

## Запуск тестов

### API-тесты (с отчётом Allure)

pytest -m api -v --alluredir=allure-results

### UI-тесты (с отчётом Allure)

pytest -m ui -v --alluredir=allure-results

### Все тесты разом

pytest -v --alluredir=allure-results

### Конкретный тест

pytest UI-tests/test_select_episode.py -v --alluredir=allure-results

По умолчанию браузер запускается в видимом режиме (HEADLESS = False в config.py). Для headless-режима поменяйте значение на True.

## Отчёты Allure

После прогона в папке allure-results лежат результаты. Отчёт открывается командой:

allure serve allure-results

## Покрываемые сценарии

### API-тесты (API-tests/):

поиск фильма по ID,
поиск фильма по названию,
поиск по ключевому слову с фильтрами,
универсальный поиск с фильтрами (cursor),
поиск актеров, режиссеров, и т.д по имени,
поиск фильма по id вне допустимого диапазона​ — корректный ответ API,
поиск фильмов с некорректными категориями — корректный ответ API.

### UI-тесты (UI-tests/):

поиск сериала по ключевому слову (трудный ребенок),
добавление фильма в «Буду смотреть»,
работоспособность паузы фильма,
работоспособность перемотки фильма,
выбор серии при просмотре сериала.
